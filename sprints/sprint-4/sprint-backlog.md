## 2. Detailed Task Breakdown

### US-13: Network Connectivity Analysis

- Calculate the number of active satellites.
- Calculate the number of active communication links.
- Identify disconnected satellites.
- Analyze network connectivity.
- Display network connectivity statistics.

### US-14: Communication Cost Analysis

- Calculate communication route costs.
- Compare available communication paths.
- Calculate average communication link cost.
- Display routing cost information.
- Analyze route efficiency.

### US-15: Network Reliability Evaluation

- Analyze network connectivity after failures.
- Calculate the number of operational satellites.
- Identify communication failures.
- Evaluate the availability of alternative routes.
- Report network reliability statistics.

### US-16: Performance Monitoring

- Monitor routing execution time.
- Record message transmission results.
- Track successful and failed transmissions.
- Compare network performance under different scenarios.
- Identify possible performance improvements.

### US-17: Graphical Statistics Dashboard

- Display active and failed satellites.
- Display active and failed communication links.
- Display network connectivity information.
- Show communication cost statistics.
- Present performance metrics graphically.

## 3. Acceptance Criteria

### US-13

### US-15
