# Sprint 5 – Testing and Validation

## 1. Testing Objective

The objective of Sprint 5 testing is to validate the complete SatNexus application by verifying module integration, routing, failure simulation, message transmission, network analytics and application stability.

## 2. Planned Test Cases

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| TC-41 | Launch the integrated application | Application starts successfully |
| TC-42 | Add and display satellites | Satellites are displayed correctly |
| TC-43 | Establish communication links | Links are created correctly |
| TC-44 | Calculate shortest communication route | Correct route is returned |
| TC-45 | Simulate satellite failure | Failed satellite is excluded |
| TC-46 | Simulate communication link failure | Failed link is unavailable |
| TC-47 | Identify alternative communication route | Alternative route is calculated when available |
| TC-48 | Transmit a message between satellites | Message is delivered successfully |
| TC-49 | Transmit a message when no route exists | Failure status is reported |
| TC-50 | Calculate network statistics | Correct statistics are displayed |
| TC-51 | Execute multiple network operations | Application remains stable |
| TC-52 | Generate and execute final build | Final application runs successfully |

## 3. Testing Approach

Testing will be performed using:

- Unit testing.
- Integration testing.
- System testing.
- Regression testing.
- Functional testing.
- Performance testing.
- Graphical interface testing.
- End-to-end validation.

## 4. Testing Results

Actual results, pass/fail status and supporting screenshots will be recorded after running the test cases.

| Test ID | Actual Result | Status |
|---|---|---|
| TC-41 to TC-52 | Pending execution | Not Tested |

## 5. Defect Tracking

All identified compilation errors, integration defects, routing problems, communication failures and graphical interface issues will be documented and resolved.

## 6. Conclusion

Sprint 5 testing will validate the integrated SatNexus application and ensure that the developed features operate together correctly before final delivery.
