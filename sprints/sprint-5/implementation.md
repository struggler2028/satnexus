# Sprint 5 – Implementation Details

## 1. Introduction

This document records the implementation activities performed during Sprint 5 of SatNexus.

The objective is to integrate all previously developed modules into a complete satellite communication application and prepare it for final validation and demonstration.

## 2. Technologies Used

- C++17
- Standard Template Library (STL)
- SFML 3.x
- CMake
- Git and GitHub
- Visual Studio Code

## 3. Implementation Modules

| Module | Responsibility |
|---|---|
| Satellite Network | Manages satellite nodes and communication links |
| Routing Module | Calculates shortest communication paths |
| Failure Simulation | Handles satellite and link failures |
| Message Transmission | Manages communication between satellites |
| Network Analytics | Calculates network statistics |
| Graphical Interface | Displays the satellite network and application results |
| Integration Module | Coordinates the complete application |

## 4. System Module Integration

The previously developed modules will be integrated into a unified application.

Integration activities include:

- Connecting the graph data model with routing operations.
- Connecting failure simulation with route calculations.
- Integrating routing with message transmission.
- Connecting network analytics with current network state.
- Integrating all components with the graphical interface.

## 5. End-to-End System Validation

The complete application will be evaluated using different network scenarios.

These scenarios will include:

- Normal satellite communication.
- Shortest-path route calculation.
- Satellite failure.
- Communication link failure.
- Alternative route identification.
- Successful message delivery.
- Failed message transmission.
- Network statistics calculation.

## 6. Defect Resolution

Compilation, integration, routing, communication and graphical interface issues will be identified and resolved.

Regression testing will be performed after important corrections.

## 7. Performance and Stability

The system will be evaluated for:

- Routing execution time.
- Message transmission reliability.
- Graph processing efficiency.
- Application stability.
- Consistency of analytical results.

## 8. Final Application Preparation

The final application will be prepared by:

- Generating the final executable.
- Verifying required libraries and dependencies.
- Organizing project source files.
- Preparing demonstration scenarios.
- Verifying application startup and execution.

## 9. Implementation Evidence

The following evidence will be added after successful execution:

- Integrated application source code.
- Final graphical interface screenshots.
- Routing and failure simulation output.
- Message transmission demonstration.
- Network analytics screenshots.
- Final application execution evidence.

## 10. Implementation Status

The implementation status and verified results will be updated as development progresses.
