# Sprint 2 – Sprint Planning

## 1. Sprint Overview

- **Project:** SatNexus
- **Sprint:** Sprint 2 – Routing and Failure Simulation
- **Duration:** To be finalized
- **Methodology:** Agile Scrum
- **Sprint Status:** Planned

## 2. Sprint Goal

The primary goal of Sprint 2 is to enhance the satellite communication network by implementing shortest-path routing, simulating satellite and communication link failures, and identifying alternative communication routes.

## 3. Sprint Objectives

- Implement shortest-path routing using Dijkstra's algorithm.
- Simulate satellite failures.
- Simulate communication link failures.
- Detect unavailable communication paths.
- Identify alternative routes between operational satellites.
- Validate network connectivity after failures.

## 4. Sprint Scope

The following features are included:

1. Shortest-path calculation.
2. Weighted path optimization.
3. Satellite failure simulation.
4. Communication link failure simulation.
5. Alternative route identification.
6. Network connectivity validation.

## 5. Team Responsibilities

Team members will collaborate on routing algorithm development, failure simulation, integration, testing and documentation.

Individual task ownership and contributions will be recorded in the sprint backlog.

## 6. Expected Deliverables

- Dijkstra shortest-path implementation.
- Satellite failure handling.
- Communication link failure handling.
- Alternative route calculation.
- Updated network simulation.
- Testing and validation documentation.

## 7. Definition of Done

A task will be considered complete when:

- Its implementation is completed.
- The routing algorithm produces correct results.
- Failure scenarios are tested.
- Alternative routes are verified.
- Code is integrated into the project.
- Documentation is updated.

## 8. Sprint Outcome

The final outcome will be recorded after implementation, execution and sprint review.
