## 2. Detailed Task Breakdown

### US-08: Message Creation

- Allow users to enter a message.
- Select source satellite.
- Select destination satellite.
- Validate source and destination IDs.
- Prepare the message for transmission.

### US-09: Satellite-to-Satellite Communication

- Establish communication between selected satellites.
- Retrieve an available communication route.
- Check network connectivity.
- Deliver messages to the destination.

### US-10: Message Forwarding

- Forward messages through intermediate satellites.
- Follow the calculated communication route.
- Prevent forwarding through failed satellites.
- Handle unavailable communication links.
- Identify unsuccessful transmission attempts.

### US-11: Transmission Status Tracking

- Track message transmission progress.
- Identify successful delivery.
- Identify failed transmission.
- Display appropriate status information.

### US-12: Graphical Message Visualization

- Highlight the selected source satellite.
- Highlight the destination satellite.
- Display the communication route.
- Visually represent message movement.
- Display transmission status in the interface.

## 3. Acceptance Criteria

### US-08
- Users can enter messages.
- Valid source and destination satellites can be selected.
- Invalid satellite IDs are rejected.

### US-09
- Messages can be transmitted between connected satellites.
- The system uses an available communication route.
- Successful delivery is reported.

### US-10
- Messages pass through intermediate satellites.
- Failed nodes and links are excluded.
- Unsuccessful delivery is handled correctly.

### US-11
- Transmission status is displayed.
- Successful and unsuccessful transmissions are distinguishable.
- The final delivery result is accurate.

### US-12
- The communication route is visually represented.
- Message movement is displayed.
- Transmission results are visible in the graphical interface.
