# Sprint 3 – Sprint Planning

## 1. Sprint Overview

- **Project:** SatNexus
- **Sprint:** Sprint 3 – Message Transmission and Network Resilience
- **Duration:** To be finalized
- **Methodology:** Agile Scrum
- **Sprint Status:** Planned

## 2. Sprint Goal

The primary goal of Sprint 3 is to implement message transmission between satellites and improve network resilience by integrating routing, failure handling and graphical visualization.

## 3. Sprint Objectives

- Implement message creation and transmission between satellites.
- Enable message delivery through intermediate satellites.
- Integrate shortest-path routing with message transmission.
- Handle message transmission when communication links fail.
- Display message transmission status.
- Improve graphical visualization of network communication.

## 4. Sprint Scope

The following features are included:

1. Message creation.
2. Source and destination selection.
3. Message transmission through available routes.
4. Intermediate satellite forwarding.
5. Transmission status tracking.
6. Failure-aware message delivery.
7. Graphical representation of message movement.

## 5. Team Responsibilities

Team members will collaborate on message handling, routing integration, network resilience, graphical updates, testing and documentation.

Individual task ownership and contributions will be recorded in the sprint backlog.

## 6. Expected Deliverables

- Message transmission module.
- Source and destination selection.
- Message forwarding functionality.
- Integration with shortest-path routing.
- Failure-aware message delivery.
- Graphical message transmission demonstration.
- Testing and validation documentation.

## 7. Definition of Done

A task will be considered complete when:

- Its implementation is completed.
- Messages can be transmitted between operational satellites.
- Intermediate forwarding works correctly.
- Failed links and satellites are handled appropriately.
- Transmission results are verified.
- Code is integrated into the project.
- Documentation is updated.

## 8. Sprint Outcome

The final outcome will be recorded after implementation, execution and sprint review.
