# Sprint 3 – Review and Retrospective

## 1. Sprint Review Overview

Sprint 3 focuses on implementing message transmission and improving network resilience in SatNexus.

The review will evaluate message creation, satellite communication, intermediate forwarding, transmission status tracking and graphical visualization.

## 2. Planned Deliverables

- Message creation functionality.
- Satellite-to-satellite communication.
- Intermediate message forwarding.
- Integration with shortest-path routing.
- Failure-aware message transmission.
- Transmission status tracking.
- Graphical message visualization.
