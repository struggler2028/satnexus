# Sprint 1 – Sprint Planning

## 1. Sprint Overview

- **Project:** SatNexus
- **Sprint:** Sprint 1 – Foundation
- **Duration:** 17 November 2026 – 18 November 2026 (planned)
- **Methodology:** Agile Scrum
- **Sprint Status:** In Progress

## 2. Sprint Goal

The primary goal of Sprint 1 is to establish the foundation of the SatNexus satellite communication network by developing the initial graph data model, defining satellite nodes and communication links, and preparing a basic network visualization.

## 3. Sprint Objectives

- Establish the project development environment.
- Create the satellite data structure.
- Implement graph representation using an adjacency list.
- Establish weighted communication links between satellites.
- Develop the initial network visualization using C++ and SFML.
- Prepare the foundation for future routing and failure recovery features.

## 4. Sprint Scope

The following features are included:

1. Project setup and repository organization.
2. Satellite creation and identification.
3. Graph-based network representation.
4. Weighted communication connections.
5. Basic graphical network visualization.

Satellite failure simulation and automatic route recovery are excluded from this sprint.

## 5. Team Responsibilities

Team members will collaborate on project setup, implementation, testing and documentation.

Individual task ownership and contributions will be recorded in the sprint backlog.

## 6. Expected Deliverables

- Organized project repository.
- Initial C++ source code.
- Satellite graph data model.
- Communication link implementation.
- Basic graphical network interface.
- Initial testing documentation.

## 7. Definition of Done

A task will be considered complete when:

- Its implementation is completed.
- Relevant functionality is tested.
- Code is integrated into the project.
- Documentation is updated.
- Supporting evidence is recorded.

## 8. Sprint Outcome

The final outcome will be recorded after implementation, execution and sprint review.
