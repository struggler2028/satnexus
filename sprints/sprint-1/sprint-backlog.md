# Sprint 1 – Sprint Backlog

## 1. Selected User Stories

| ID | User Story | Priority | Story Points |
|---|---|---|---:|
| US-01 | Project Setup | High | 2 |
| US-02 | Graph Data Model | High | 5 |
| US-03 | Network Visualization | High | 5 |

**Total Story Points: 12**

## 2. Detailed Task Breakdown

### US-01: Project Setup

- Create and organize the GitHub repository.
- Establish the source code directory.
- Configure the C++ development environment.
- Configure the SFML graphics library.
- Prepare the CMake build configuration.

### US-02: Graph Data Model

- Define the Satellite structure.
- Assign unique IDs to satellites.
- Store satellite names and coordinates.
- Implement the adjacency list.
- Implement satellite creation.
- Implement weighted communication links.
- Validate satellite connections.

### US-03: Network Visualization

- Create an SFML application window.
- Draw satellite nodes.
- Draw communication links.
- Display satellite names and IDs.
- Display communication link weights.

## 3. Acceptance Criteria

### US-01
- Repository structure is organized.
- Required source files are available.
- The project can be configured for compilation.

### US-02
- Satellites can be created with unique IDs.
- Communication links can be established.
- Link weights are stored correctly.
- Invalid connections are rejected.

### US-03
- Satellites are displayed graphically.
- Communication links are visible.
- Satellite labels and link weights are readable.
